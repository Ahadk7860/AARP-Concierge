# Phase 2 Track Protocol

Each track starts from the same committed foundation, in its own worktree. One coherent
prompt and one conventional commit at a time. Never merge, rebase, force-push, edit a
frozen contract, or borrow another track's path.

Before every handoff: run the named tests, run `bash scripts/check-ownership.sh <track>`,
record evidence and unresolved gaps in `NOTES.md`, and leave a clean worktree. A blocker
means commit safe progress and report; it never licenses a guessed contract.

K starts only after reviewed merges. Its proof must use real producer/consumer process
boundaries; two stubs agreeing is not a passing join.
